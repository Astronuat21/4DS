Hallo! Welcome to the Github Repository for the 4DS.

4DS is a solo project by Astronuat21 (me!!) aiming to make a dual screen console _akin to the Nintendo DS's_ but with stronger hardware, better battery life and specs in general. The device is also much larger than the ones you might have at home; coming in at around 19x11.5x3cm, the device is better suited for people with bigger hands who may find uncomfortability using even the stardard XL models. The hardware mostly tops the Switch, using the Lattepanda Mu SoC and it's N100 CPU, alongside 16GB of RAM and expandable Gen 3 SSD storage. If you so choose, this project should also be compatible with the upgraded N305 version (although it will be almost useless due to its higher PSU requirements).

This repository contains all the PCB files used in this project, including schematics and circuit boards. **Assuming everything works,** you should be able to reproduce the exact boards I used and reprint them for yourself. Also included are all the 3D files used in 3D printing or other purposes as well as some *outdated -_-* images to look at. They can be found in **/3D Models** and **/Images** respectively. You will also need some of the additional programs included for things like the RP2354 Microcontroller, alongside some other helpful scripts, which can be found in **/Programs**.

I built this to challenge myself to make a console that I would be proud to daily drive. My 2DS XL is great, but it definitely can't play my Steam library, and while I _can_ fit a Switch in some pockets, it dosen't quite have the extensive game library (for what I actually play). Unlike the _New (or not really)_ DS, which can play NES, SNES, GB/GBA, DS, and 3DS games as well as N64 and Gamecube to some extent. The Switch needs Nintendo Online for that as far as I know, and I HATE SUBSCRIPTIONS (Also its not even all the games). So thats where I've ended up now, with the great opportunity to flex superior intellect on some friends.
